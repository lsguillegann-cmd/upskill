# UPSKILL TRAINING

## Goal
Learn and practice Claude Code, GitHub, branching, commits, deployments, and safe AI-assisted development.

## Working Rules
- Never edit production directly.
- Always work in a separate GitHub branch.
- Inspect the project before making changes.
- Test changes before merging.
- Never expose API keys, passwords, tokens, or secrets.
- Document important changes.
- Ask for clarification when requirements are unclear.
- Keep the main branch stable.

## Current Training Tasks
1. Practice Claude Code inside VS Code.
2. Create and edit files.
3. Connect project to GitHub.
4. Practice branch, commit, push, and pull request.
5. Build a simple practice app.
6. Deploy the practice app.
